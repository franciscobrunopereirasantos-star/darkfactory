# Episódio 01 — A ponte de papelão

`placas/`: cenário-mestre C com as peças de papelão projetadas a partir da planta aprovada (camadas do par técnico + homografia de `geometria-ponte.json`).
- p = posição inicial (vão junto à peça do fundo)
- t = tentativa (L encostado na peça do fundo, vão junto à entrada)
- r = posição final (L girado 90°, caminho completo)

As versões `-espelhada` servem para gerar as cenas com o ursinho no braço que o gerador prefere; o episódio inteiro é desespelhado na montagem. Nenhuma imagem de personagem fica neste repositório.
